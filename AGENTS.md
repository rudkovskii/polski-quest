# AGENTS.md: «Ферма» (polski-quest)

Браузерная пиксельная игра по польскому в духе Stardew Valley для Димы («Шэф»): фермер выращивает слова и фразы.
Репозиторий = папка `Игра/app/` (`rudkovskii/polski-quest`, Pages `/polski-quest/`). Запрос и решения — `../ФЕРМА.md`.
Старая игра («Pierogi i Przypadki») убрана из дерева: тег `archive-v1`, ветка `archive/v1`. Модули оттуда бери только оттуда.
`CLAUDE.md` — копия этого файла (не симлинк): меняешь AGENTS.md → скопируй.

## Работа
- Одна сессия = одна работа из `../ФЕРМА.md` (F-01 каркас, F-02 база A1, F-03 словарь и грядки, F-04 плейтест).
- В конце: `npm run check` зелёный, коммит по-русски, без пуша в `main` без просьбы.
- Версии в package.json точные, зависимости без отдельной задачи не обновляй. Phaser 4.2.1, не Phaser 3: сомневаешься в API —
  смотри `node_modules/phaser/types/phaser.d.ts` и `node_modules/phaser/skills/v3-to-v4-migration/SKILL.md`.
- **Звук вслух на проверках не играть**: dev-прогон только с `?mute=1`. `npm run audio` пишет файлы, но не играет.

## Слои (ловит `npm run check:layers`)
- `src/systems/**` без `platform/`: чистая логика (ответы `answer.ts`, сохранение `save.ts`, шина `bus.ts`, политика обновления).
  Без `phaser`, браузерных глобалов, `Date.now()` (время приходит параметром).
- `src/systems/platform/**`: адаптеры браузера (хранилище IndexedDB, озвучка, PWA, часы).
- `src/world/**` и `src/scenes/**`: ходьба, карты, камера, Phaser-сцена. Модель `world/location.ts` чистая (без Phaser), её гоняют тесты.
- `src/ui/**`: DOM-оверлей (HUD, настройки, пузырь, d-pad, экранная клавиатура `ui/keyboard`). Без `phaser`, без `world|scenes`.
- `src/input/**`: клавиатура, d-pad, тап → intents в шину. Прямой `keydown`/`pointerdown` только здесь и в `ui/keyboard`.
- Склейка слоёв только в `src/main.ts`. Связь мира и экранов — только через `bus` (`src/types/bus.ts`).

## Запрещено (ловит `npm run check:banned`)
- Phaser 3 API (`preFX`, `postFX`, `BitmapMask`, `Geom.Point`, `tintFill`, `Pipeline`, `Mesh`, `Plane`, `Phaser.CANVAS`…).
- Текст в canvas (`add.text`, `add.bitmapText`): весь текст рисует DOM-оверлей.
- `localStorage`/`indexedDB`/`fetch`/`Date.now()` в чистых `systems`.
- Слушать `keydown`/`pointerdown` в сценах и экранах напрямую.
- Правка `public/atlas/*` и `public/audio/*` руками: только `npm run sprites`, `npm run audio`.

## Арт (sprite-as-data)
- Всё нарисовано кодом данных: `tools/art_*.py` рисуют `art/sprites/*.sprite.json` (`npm run art`), `npm run sprites` собирает атлас
  `public/atlas/` (`custom` — спрайты, `farm` — тайлсет 16×16). JSON можно править руками; кадры кратны 16.
- Свет и палитра как у жаб на дашборде (`Планы/assets/dashboard-frogs-sprites-sdv.js`): у материала один средний тон в
  `art/materials.json`, `tools/art_ramp.py` (`sdv_ramp`) строит рампу `<материал>.0…4` и контур `.o` (тени в красно-фиолетовый, блики в
  жёлтый; свет сверху-слева). Hex в спрайтах запрещён, только имена. Новый цвет = новый материал, а не случайный hex.
- Альфы в атласе нет: мягкие тени под объектами рисует сцена полупрозрачными овалами.

## Мир (F-01)
- Карты ASCII: `content/maps/home.json`, `farm.json` (формат — `src/types/map.ts`). `parseAscii` + тайлсет; объекты: `prop`, `exit`, `plot`, `spot`.
- Управление: стрелки/WASD, d-pad (удержание = идти, короткий тап = шаг), тап по карте = дойти, A/E/Пробел = действие, тап по объекту = дойти и действие.
- Тап по объекту (P1a): попадание по видимому спрайту (`LocationModel.targetAtPoint`), герой идёт на клетку подхода со стороны лица
  (`face` у prop, по умолчанию `down`; свои клетки — `approach`), занято — ближайшая другая, поворачивается и шлёт `interact`.
  Тап по двери (и по стене над выходом) проводит сквозь неё. Тесты — `tests/approach.test.ts`.
- D-pad виден сразу на сенсорных устройствах (`detectCoarse`: pointer/any-pointer coarse, `maxTouchPoints`) и после перезагрузки
  (флаг `touch` в `Save.hints`). Первые шаги новичка — `ui/hintsGuide.ts` (`guide:goal` → сцена шлёт `fx:guide`; флаги `guide:desk`, `guide:board`).
- Камера: маленькая карта (дом) на ступень крупнее, если по высоте влезает между HUD и d-pad (`pickZoom(..., usableH)`, iPhone: дом zoom 3).
- Герой `hero` (16×32, 4 стороны × 3 кадра), портрет `hero_portrait` 32×32, кот `cat` (Rudy, 16×16: ходит, сидит, умывается, спит).
- Кот: идёт за героем по следу, не стоит на двери, подходах к дверям и объектам, на клетке героя, перед ним и над ним; уступает дорогу;
  в доме при долгом покое спит у кровати (`spot:cat_sleep`).

### Контракт для F-03: событие `world:interact`
Шлёт сцена при A рядом с интерактивным объектом или тапе по нему. Мир ничего не открывает: слушатель решает, что показать.
`{ location: 'home'|'farm', use, id, key, label, tile, via: 'action'|'tap', facing }`, где `use` (= `id`):
`desk` (Słownik на столе дома), `shelf` (банки, Spiżarnia), `bed` (кровать), `board` (выбор мини-игры, ферма), `bin` (коробка урожая, ферма).
Пока слушает только заглушка `ui/bubble.ts` (пузырь с названием; в игре не подключена). На время экрана F-03 шлёт `world:input {enabled:false}` (герой встаёт,
ввод идёт в оверлей), потом `true`. Участок грядок — объект `plot:garden` (6×4 в `farm.json`, запас под расширение в `reserve`).
Прочие события: `world:exit` (шаг в дверь), `world:position` (остановка героя, пишет сохранение), `hud:xp {level, ratio}` (F-03 шлёт опыт).

- Путь к A1 (V11c, `systems/xp.ts`; заменил A0.x из P1b): очки = выращенное слово 1 + короткая фраза 1 + фраза сборки (≥ 3 плиток) 2 + растущее частично
  (после первого ответа: семечко 0,1 / росток 0,3 / кустик 0,6 веса); перезревшее остаётся выращенным. A1 = вся база (1167 слов + 164 короткие + 2 × 234 сборки = 1799 очков, считается из контента).
  20 уровней просто с номерами, без званий и значков («Poziom 1 · Уровень 1» … «Poziom 20 · Уровень 20», до первого порога «Старт», итог «A1»; с 18.10 по просьбе Шэфа, слова «подуровень» в интерфейсе нет), пороги 5, 15, 30, 50, 80, 120, … до 95 % пути на 20-м (`thresholds(total)`). Уровень не хранится: выводится из состояния огорода, старые сохранения пересчитываются сами.
  `hud:xp {level («Уровень 7» / «Старт» / «A1»), sub 0…20 (21 — A1), of: 20, ratio, pct, pos, toNext, growing, gain, up}`. HUD «Уровень 7/20» + полоска (подсказка «До уровня 8: N оч.»; `levelLabel`/`nextTarget` в `systems/xp.ts`) + «до A1: 12%», тап → `ui/levelUp.ts` `mountPath` («Путь к A1»: заголовок «Уровень 7 из 20», «До уровня 8: ещё N очков», лестница с номерами в пиксельных плашках, пройденные ✓, финал «🏆 A1 · от 1799 оч.», выращено из скольких, честная строка про ориентир 1100–1500 слов);
  `mountLevelUp` — карточка нового уровня «Новый уровень! · 7 из 20» (на `hud:xp {up}`; звук — тот же `up` в `connectSfx`, под выключателем и `?mute=1`). `FarmStats.path/base/thresholds/sessionGain`, `AnswerResult.path {from,to,sub,pl}` → строка пути в итоге раунда и «Уровень 2/20 · +0,4 уровня» в итоге раунда и дня. Очередь `pickTask`
  (P2a — ведёт к урожаю, а не размазывает ответы): перезревшие → кому верный ответ сейчас даст урожай → кому сегодня не хватает зачёта дня
  (рост начат раньше) → кому не хватает этой стороны (игра 2 — «по-польски», игра 1 — «с польского»); внутри — ближе к урожаю раньше; дальше
  прежнее: у кого сегодня меньше ответов, кому ответ поможет. Растение не повторяется чаще раза в min(3, пул−1) заданий (`REPEAT_GAP`; P3a: было 5). Симуляция
  (`tests/p2a.test.ts`): тема 19 слов, 3 дня по 20 ответов, 85% → ≥ 8 урожаев и в играх 1+2, и только в одной.
  P3a (фокус): рабочий набор `FOCUS_SIZE` = 8 ближайших к урожаю растений (по стадии, дням, каплям), которым сегодня ещё есть что дать; остальные — каждое
  5-е задание (`FOCUS_EVERY`, из них берётся самое продвинутое). «Созревшее на сегодня» (`settledToday`: куст с зачётом дня, «по-польски» был, урожай только завтра)
  уходит в конец очереди, пока есть другие. Симуляция (`tests/p3a.test.ts`): 19 слов, 3 дня по 15 ответов, 75% → в среднем ≈ 5,3 урожая (без фокуса ≈ 4,7).
  «Наоборот»: в играх 1/2, если слову для куста/урожая не хватает другой стороны, задание даётся в другую сторону выбором (игра 2 — с польского,
  игра 1 — на польский, без ввода), пометка «↔ наоборот» в шапке; не чаще каждого 3-го задания (`REVERSE_EVERY`), не по «Повторить» (`wantsReverse`); P3a: не в первые 10 ответов (`REVERSE_AFTER`) и не раньше 2 ответов слова в прямой стороне (`REVERSE_MIN_DIRECT`, `ItemState.sideAns`).
  Доска (P3a): при закрытых играх 3/4 — «Сборка фраз откроется, когда слова фразы подрастут до ростка», ближайшая фраза (`farm.phraseHint`), «Нужно: …», кнопка «Посадить недостающие» / «Посадить фразу».
- Прогресс до урожая (P2a): `garden.progressText` («ещё 1 полив до ростка», «нужно ответить по-польски», «до урожая: ещё 1 день») — в задании

### P2b: навигация новичка, жаргон, мелочи
- Указатель первых шагов висит над ковриком у двери: пока есть `guide:goal`, тап по клетке рядом с дверью = выход (`targetAtPoint(..., { doorZone })`).
  Цель за кадром — стрелка у края экрана на луче от героя (`edgePoint` в `ui/hintsGuide.ts`).
- Термины: `ui/glossary.ts` (`MODE_NAME` — названия игр по-русски + польское мелко, `STAGE_INFO` — «семечко / росток / кустик / урожай / перезрело — повтори» + значок,
  `createTips` — «Банка = выученное слово», «Мешок = семена, которым не хватило грядки» один раз; флаги `tip:jar`, `tip:bag` в `Save.hints`). `STAGE_RU` в `panel.ts` берёт подписи оттуда.
  P2c: заголовок панели мини-игры берёт `MODE_NAME` (русское название, польское мелко, рядом метка «↔ наоборот»); `MODE_TITLE` удалён. Ряд вариантов — кнопки фиксированной высоты (`grid-auto-rows`, до 3 строк внутри).
  Тексты `progressText` по словарю: «до кустика», «слово выучено и лежит в банке», «один верный ответ, и слово снова в банке».
- Подпись растения: `LabelGate.arm()` на старте сцены, при `world:input enabled:true` и выходе из мини-игры: растение у героя молчит, пока он не отойдёт и не вернётся.
- Обновление сборки (`systems/update.ts`): `busy` (открыт экран или мини-игра) → тост «Есть новая версия · Обновить», иначе тихая перезагрузка с `flush`; защита от петли 60 с;
  как только экраны закрылись, политика спрашивается снова. Коробка урожая: подход слева (`face: left` в `farm.json`), голова героя её не закрывает.

### Пёстрый огород: вид растения по слову
- Существительное растёт мини-предметом на кусте (мини-машинка), слово-цвет — ягодой/овощем своего цвета, остальное (глаголы, прилагательные, наречия) — 16 разных кустов. Фразы `p.` и единицы v2 (`geo.`, `hymn.`, `symbol.`, `date.`, `hol.`) — прежние `crop_*`.
- `systems/plantLook.ts` (чистый): `lookOf(id, word?)` → `PlantLook` (`object {icon, variant}` / `color {fruit, variant}` / `plant {variant}` / `phrase` / `unit`), `framesOf(look)` → кадры атласа (росток, кустик, урожай, предмет с отступом `slot`, плод над головой). Слово базы берётся из `content/plants/mapping.json`; слово вне базы (свои слова Шэфа `w.custom.*`, тема «Święta») — `resolveWord` по `rules.json` (цвет → не существительное → лемма → основа перевода → тема → регулярки перевода → `cat_misc`; вариант и плод = `crc32(id)`); нет слова — куст по id. Детерминировано.
- Предметы сидят только на низких кустах `OBJECT_VARIANTS` (0,1,3,5,6,12,13): на высоких стебель торчал из-под предмета. Нечитаемые иконки (`horse`, `wifi`, `yoga`, `dance`) подменяются иконкой темы (`ICON_SWAP`).
- Сцена: `PlantView.look` (ставит `farm.ts`), `scenes/farmLayer.ts` — семечко и перезревшее общие, росток/кустик/урожай по виду; у предмета отдельный спрайт `ic` с тем же якорем (подпрыгивание, дрожь, рост общие); плод над головой при сборе — тот же предмет (`framesOf().held`). В банке Spiżarnia у слова тот же мини-предмет (`ui/pantry.ts` → `ui/atlasIcon.ts`).
- Свои слова: перед темой и общим предметом `resolveWord` сверяет перевод с подписями мини-предметов (`ICON_BY_RU`: «пельмени» → `dumpling`).
- Арт: 49 листов `art/plants/*.sprite.json` (кусты `plant_v00…v15`, плоды `plant_fruits_*`, иконки `plant_icons_*`), перекрашены на СУЩЕСТВУЮЩИЕ материалы проекта (палитра 319/320, новых нет): `python3 tools/plants_import.py --src <Игра/data/plants>` (ближайший материал по рампе, правки — `OVERRIDE`), рисует их в `art/sprites` `tools/art_plants.py` (`npm run art`), упаковка после v2 (`LAST_PREFIXES` в `sprites_build.py`). `ATLAS_SIZE` в `ui/stageIcon.ts` = размер атласа (тест `farmui` сверяет).

### Свои слова («＋ Своё слово», тема «Moje słowa»)
- Шэф пишет русское слово, игра даёт польский перевод офлайн: словарь `public/dict/rupl.json.gz` (Викисловарь, CC BY-SA 4.0, 39 742 леммы, описание — `../data/rupl/README.md`), не в precache SW, грузится по требованию загрузчиком `systems/platform/rupl.ts` (`createRuplLoader`: gzip по первым байтам `1f 8b`, иначе чистый JSON; неудача не запоминается). Транскрипция — `systems/translit.ts` (порт `translit.py`, `@ts-nocheck` намеренно; тест сверяет с `tr` всех слов A1).
- Чистая логика `systems/customWords.ts`: `normRu` (регистр, ё→е, ударение), `lookupRu` (`d[q] ?? d[f[q]]`, Object.hasOwn: «constructor» не находит), `baseMatches` («это слово уже есть в базе» по русскому переводу A1 и темы праздников), `customId` (`w.custom.<хеш пары польское|русское>`), `normalizeCustom`, `forgetItem`.
- Хранение: `Save.custom: CustomWord[]` (id, pl, ru, pos, gender?, ex?, added), без повышения `SAVE_V` (старое сохранение читается как `[]`). Рост — обычный огород (`Save.garden`), слово живёт в реестре содержимого: `content.ts` `setCustomWords` меняет **на месте** `ALL_WORDS`/`WORD_BY_ID`/`TOPICS` (тема `moje` в конце, пока есть слова) — вызывает `createFarm` (`FarmDeps.customs {load, save}`). Свои слова вне `A1_IDS`: путь к A1 их не считает, опыт и Spiżarnia — считают.
- `FarmApi.custom?: CustomApi` (`add`, `update`, `remove`, `list`, `base`); необязательное поле, чтобы чужие фейки ферм не ломались: без него вкладки нет. `remove`: убирает слово, посадку, ответы и грядку; растущее слово экран удаляет только с подтверждением (в карточке словаря).

## Сохранение
`systems/save.ts` (модель, экспорт/импорт файлом) + `platform/storage.ts` (IndexedDB → localStorage → память, запись с дебаунсом,
аварийная копия при уходе). v2: позиция героя, звук, огород (`garden`: посадки, журнал, грядки).
Сброс = автоэкспорт файла, потом стирание.
V11a: запись после каждого ответа и посадки (дебаунс 400 мс, не позже 1 с — `DEFAULT_MAX_WAIT_MS`), при `pagehide`/`visibilitychange:hidden`/`freeze`; `requestPersist()` на старте.
Сбой записи: хранилище повторяет (1,5 с, ×2 до 10 с) и шлёт `onWrite` `{error|saved}`; HUD (`ui/hud.ts`): тост «Не сохранилось, повторяю» и галочка ✓ на 1 с после записи огорода.
`load()` берёт более свежую из IndexedDB и localStorage (запись могла уйти в запасной бэкенд). Настройки: «Последнее сохранение: ЧЧ:ММ»; раз в 7 дней напоминание скачать копию
(`systems/backup.ts`, метки `backup:<мс>` и `backup-remind:<мс>` в `Save.hints`; экспорт ставит `backup:`).

### v2: карта на весь лист и возврат из игры (19.10)

### Бобёр (просьба Шэфа 19.10: «периодически на участке появляется бобёр, чем выше уровень, тем чаще, а потом поселится»)
- **Слои.** `systems/beaver.ts` — чистая логика (шанс, броски, лимит, заселение, `createBeaver({load, save, now, level, tz})`); `world/beaverLife.ts` — поведение на карте (`BeaverLife`, как `catLife.ts`, плюс `beaverHost(model)` — что проходимо, где стоять, где грызть); `scenes/beaverLayer.ts` — спрайт, тень, плавное появление; `ui/beaver.ts` — карточка и пузырь. Склейка: `main.ts` кладёт `beaver` (API) и `decor` в реестр Phaser, `World.ts` создаёт слой только на ферме.
- **Уровни 0–9 (`xp.ts`): гость.** Шанс визита `10 % + 50 % × L/9` (линейно: ур. 0 — 10 %, 3 — 27 %, 5 — 38 %, 9 — 60 %, `visitChance`). Бросок на входе на ферму (слот 10 мин) и на каждой смене игрового часа при открытой ферме (`tick` раз в 5 с проверяет слот); ответ детерминирован: зерно = день + вид броска + слот (`rollUnit`). Не чаще одного визита за 10 минут (`VISIT_GAP_MS`, `Save.beaver.lastVisit`). Визит 1–3 минуты (`stayMsOf(seed)`), вернулся на ферму до конца — бобёр ещё тут (`active`). Появляется у кромки участка, бродит, сидит, умывается, грызёт веточку у дерева, куста, забора, смотрит на героя, уходит к ближайшему краю. Во время мини-игры с автобегом новые гости не приходят.
- **Уровень ≥ 10 (`SETTLE_LEVEL`): хозяин.** Гостей уже нет; `trySettle()` один раз пишет `Save.beaver.settled` (дата, не сбрасывается, даже если уровень «упадёт»). main.ts заселяет на ферме, когда ничего не открыто, карточка уровня погасла (6,5 с) и герой не стоит там, где вырастут хатка с прудом: кладёт `beaver.home` в `registry.decor`, шлёт `beaver:settled` (карточка «Bóbr zamieszkał na farmie! · Бобёр поселился на ферме», один раз), `World` пересоздаёт сцену на той же клетке. Хатка `beaver_lodge` 2×2 (22,15) и пруд `beaver_pond` 2×3 (24,14, 2 кадра ряби) — в `farm.json` с `unlock: "beaver.home"` (`PropObject.unlock`, `withDecor`): без ключа на карте их нет. Бобёр живёт в радиусе 8 клеток от лаза (23,17): грызёт, плавает, ныряет, выглядывает из пруда (клетки воды проходимы только ему), сидит, умывается, иногда прячется в хатку; ночью (21–06 по местному времени) спит в ней и не виден.
- **Не мешает.** Не стоит на клетке героя и его следующего шага (герой шагнул на него — бобёр отбегает; шагал на ту же клетку — разворачивается), на дорожке, грядке и участке под грядки (с запасом в клетку), у двери и точки входа, на подходах к объектам; кот и бобёр не делят клетку (кот обходит его как препятствие, бобёр — кота), кот иногда смотрит на бобра.
- **Тап/A по бобру** — `world:interact {use: 'beaver', label: 'Bóbr · бобёр'}` (в модели это живой объект `beaver:0`, `LocationModel.beaver`), бобёр поворачивается к герою; `ui/beaver.ts` показывает пузырь с 🔊 (`audio:play {id: 'beaver', text: 'Bóbr'}`, под выключателем звука, с `?mute=1` — в консоль).
- **Сохранение.** `Save.beaver {settled, lastVisit, visits}` (`normalizeBeaver`, старое сохранение без раздела читается как «бобра не было», `SAVE_V` тот же).
- **Арт** (`tools/art_beaver.py`, 3 листа, новых материалов нет: мех `loose`/`wood_dark`, брюхо `sack`, хвост `soil`, резцы `cream`, ветки `wood`, вода `water`): `beaver` 16×16, 32 кадра (ходьба в 4 стороны, сидит боком и спереди, умывается, грызёт, плывёт, выглядывает, ныряет, бежит; влево — `flip`), `beaver_lodge` 32×32, `beaver_pond` 32×48. Упаковка после всех (`FINAL_PREFIXES` в `sprites_build.py`), `ATLAS_SIZE` в `ui/stageIcon.ts` — 1488. Старый `bobr` из `archive/v1` (прораб в каске, 16×16, фронт) не подошёл: нужны другие позы и профиль, нарисован заново.
- **Проверка.** `?dev=<id>&blvl=N` подменяет уровень (только с `?dev=`, профиль отдельный); `__pq.world().beaverLayer.force('visit' | 'resident')` зовёт бобра мимо броска, `.state` — где он. Вкладка в скрытой панели не крутит кадры: `__pq.game.step(t, 16)` в цикле. Тесты `tests/beaver.test.ts`.
